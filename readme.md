# Agent-Share

A zero-dependency Python TUI to inspect, configure, toggle, and share MCP servers, skills, agents, and plugins across AI CLIs like Claude Code, Codex, Antigravity, and Pi Agent.


https://github.com/user-attachments/assets/a5162b06-39d4-4bd2-b596-c839af0ef029


## Supported Tools
* Claude Code
* Codex
* Antigravity 2.0
* Pi Agent


## Keyboard Shortcuts
* `↑` / `↓` : Navigate list
* `←` / `→` : Change CLI view tab
* `Space` : Mark/Unmark asset
* `Ctrl + A` : Mark all visible assets
* `Enter` : Share/transfer marked assets to another CLI
* `e` : Toggle enable/disable status
* `d` / `Delete` : Delete marked assets
* `k` : Cycle asset type filter
* `s` : Cycle sort method
* `Ctrl + F` : Search assets
* `q` / `Ctrl + C` : Quit
